# 🎮 Tic-Tac-Toe Game

A simple **Tic-Tac-Toe game built with Python** where you play against the computer.

## 🕹️ How It Works

- The **computer plays as X**
- The **user plays as O**
- The computer randomly selects an available position
- The user chooses a position by entering a number from **1 to 9**
- The game checks for a winner after every move
- If all positions are filled without a winner, the game ends in a **draw**

## ✨ Features

- 🎲 Random computer moves
- 🔢 User can choose positions from 1–9
- 🚫 Prevents already occupied positions
- ⚠️ Handles invalid input
- 🏆 Detects the winner
- 🤝 Detects a draw

## 🛠️ Built With

- Python
- Random module
- Lists
- Functions
- Loops
- Conditional statements
- Try/Except
